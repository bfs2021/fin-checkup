# 블로그·README 에 붙이기

회사 페이지(`/c/<종목코드>/`) 맨 아래 **"블로그에 붙이기"** 에 그 회사용 코드가 이미 만들어져 있습니다. 거기서 복사하는 게
가장 쉽고, 이 문서는 플랫폼마다 어디에 붙이는지와 지켜 줄 것 한 가지를 적었습니다.

아래 예시는 삼성전자(005930)입니다. 다른 회사는 주소의 종목코드만 바꾸면 됩니다.

| 무엇 | 주소 |
|---|---|
| 회사 페이지 | `https://younghwan91.github.io/fin-checkup/c/005930/` |
| 배지 (SVG) | `https://younghwan91.github.io/fin-checkup/badge/005930.svg` |

## 지켜 줄 것: 배지는 늘 회사 페이지로 연결

배지에는 사업연도와 신호 개수(🟢·🟡·🔴·⚪·⊘·⚫ 몇 개)만 있습니다. **점수나 등급이 아니고**, 배지만 봐서는 어떤 지표가
어떤 계산식·경계값으로 그 색이 됐는지 알 수 없습니다. 그 근거와 출처(DART), 면책 문구는 회사 페이지에 있습니다.

- 배지 이미지를 쓸 때는 **회사 페이지 링크로 감싸 주세요** (아래 코드가 모두 그렇게 되어 있습니다).
- 배지를 잘라 사업연도를 지우거나, 신호 개수를 "점수"·"등급"으로 소개하지 말아 주세요.
- 배지는 측정값이지 투자 의견이 아닙니다. 글에서 매수·매도 판단의 근거로 내세우면 이 도구가 하지 않는 말을
  대신 하게 됩니다 ([`REGULATORY.md`](REGULATORY.md)).

배지 숫자는 사이트가 새로 빌드될 때 함께 바뀝니다. 글을 쓴 시점의 값을 남기고 싶다면 본문에 사업연도를 함께 적어 두세요.

## 플랫폼별

### 네이버 블로그

스마트에디터 ONE 은 HTML 편집이나 외부 이미지 주소 삽입을 지원하지 않습니다. 그래서 배지 대신 **링크 카드**를 씁니다.

1. 본문에 회사 페이지 주소를 붙여 넣습니다: `https://younghwan91.github.io/fin-checkup/c/005930/`
2. 에디터가 페이지 제목·설명(Open Graph)으로 미리보기 카드를 만들어 줍니다. 카드를 누르면 회사 페이지로 갑니다.

배지를 그림으로 캡처해 올리는 경우에도 캡처 바로 아래에 회사 페이지 주소를 적어 주세요.

### 티스토리

글쓰기 화면 오른쪽 위 **기본모드 → HTML** 로 바꾸고, 원하는 자리에 붙입니다.

```html
<a href="https://younghwan91.github.io/fin-checkup/c/005930/"><img src="https://younghwan91.github.io/fin-checkup/badge/005930.svg" alt="fin-checkup 삼성전자 2024 재무 신호등"></a>
```

다시 기본모드로 돌아와도 배지와 링크가 남습니다. 링크 카드를 쓰고 싶으면 네이버와 같이 주소만 붙여도 됩니다.

### GitHub README · 마크다운 문서

Velog 와 같은 마크다운입니다. GitHub 는 외부 이미지를 자체 프록시로 캐시하므로 배지가 바로 바뀌지 않을 수 있습니다.

```markdown
[![fin-checkup 삼성전자 2024 재무 신호등](https://younghwan91.github.io/fin-checkup/badge/005930.svg)](https://younghwan91.github.io/fin-checkup/c/005930/)
```

### 그 밖의 HTML 을 받는 곳

티스토리와 같은 HTML 조각을 쓰면 됩니다. 사이트는 쿠키·추적 스크립트가 없어서, 배지를 붙여도 읽는 사람의 정보가
이 사이트로 따로 모이지 않습니다(이미지 요청은 GitHub Pages 가 받습니다).

## 공유 링크·미리보기 카드

회사 페이지 위쪽의 **링크 복사** 버튼은 페이지 주소만 복사합니다(`?`·`#` 뒤를 떼고, 추적 파라미터를 붙이지 않습니다).
메신저·SNS·블로그에 그 주소를 붙이면 각 서비스가 페이지의 제목·설명(Open Graph·트위터 카드 메타)으로 미리보기를 만듭니다.
미리보기 문구에는 사업연도·보고서 종류와 "지표마다 계산식과 경계값을 함께 적었습니다" 가 들어 있고, 카드를 누르면
그 근거가 있는 회사 페이지로 갑니다.
